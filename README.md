# PureLoop Africa Limited — Company Website

A responsive premium corporate website built for PureLoop Africa Limited.

## Content
- Company introduction, vision, mission and core values
- Six service areas: waste prevention, collection, transportation, treatment, recycling and environmental consultancy
- Sectors served and circular-economy approach
- Environmental, social and economic sustainability, CSR and SDG alignment
- Health, safety and environment commitments
- Management profiles and direct contact links

## Features
- Responsive desktop, tablet and mobile layouts
- Mobile navigation, smooth in-page navigation and back-to-top control
- Search metadata, Open Graph cards, Organization structured data, robots.txt and XML sitemap
- Accessibility labels, meaningful image alternatives and reduced-motion support

## Publish on GitHub Pages
1. Merge the pull request into main.
2. In Settings → Pages, select Deploy from a branch, branch main, folder / (root), and Save.
3. Wait for the Pages deployment to complete.

Expected public URL: https://matharabrian70-ux.github.io/PureLoop_Africa/

## SEO launch checklist
SEO improvements provide a strong technical foundation, but no site can guarantee a first-place Google ranking. After publishing, verify the site in Google Search Console, submit the XML sitemap, confirm that public business details are accurate, request indexing and monitor search performance.

Company contact details are based on the supplied company profile and business cards. Confirm these remain current before public launch.
