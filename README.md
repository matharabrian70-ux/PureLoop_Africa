# PureLoop Africa website

Responsive static company website for PureLoop Africa Limited.

## Publish
This site is prepared for GitHub Pages from the repository root. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. Expected URL: `https://matharabrian70-ux.github.io/PureLoop_Africa/`.

## Included
- Responsive desktop, tablet and mobile layout
- Company profile content: six services, sectors, sustainability, CSR, SDG alignment, HSE and contacts
- Mobile navigation, in-page links, back-to-top and reduced-motion support
- SEO title, meta description, canonical URL, Open Graph metadata, structured data, robots.txt and sitemap.xml

SEO setup does not guarantee first place on Google. Verify the published site in Google Search Console and submit the sitemap.
